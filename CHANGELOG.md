# Changelog
All notable changes to Greenhill Food Co-op ordering system will be recorded here.
This changelog follows the Keep a Changelog format.

## [v0.1.0-sprint 1]
### Added
  Weekly food batch pre-order HTML form
  Quantity input fields and client-side validation logic
  Order submission function with auto-generated order reference number
  Navigation links to homepage and product catalogue 
  Environment configuration templates: dev.env and prod.env
  Simple deployment helper script deploy.sh

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-05

### Added
- Initial project scaffold with Flask setup
- Member, Product and Round database models
- Basic routes: home, product list, coordinator dashboard
- GitHub Actions CI workflow for running tests
- Feature branch and pull request workflow
